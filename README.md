# crop-disease-prediction

A simple crop disease prediction starter project built with Flask.

## Features
- Upload a leaf image
- Basic image-based disease detection prototype
- Simple web UI

## Setup

1. Create a virtual environment:
```bash
python -m venv venv
source venv/bin/activate
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the app:
```bash
python app.py
```

4. Open in browser:
```text
http://localhost:5000
```

## Notes
This is a starter project for disease detection. For production use, connect it to a trained deep learning model and a larger labeled dataset.
